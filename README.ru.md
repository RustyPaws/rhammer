# rhammer

[English](README.md) | **Русский**

> 🤖 Этот проект создан с помощью Claude AI (Anthropic), в основном как эксперимент по проверке возможностей ИИ. Он не задуман как конкурент кому-либо.

**rhammer** — редактор уровней для карт движка Source в стиле Valve Hammer, написанный на Rust с использованием [egui](https://github.com/emilk/egui). Он читает и записывает файлы `.vmf` и использует игровые конфигурации в духе Hammer (описания сущностей FGD, компиляторы), поэтому легко встраивается в привычный процесс создания карт для Source.

> Статус: нестабильно. Возможны шероховатости.

## Возможности

- **Поддержка VMF** — открытие, редактирование и сохранение карт `.vmf`; инстансы `func_instance` загружаются и отображаются во вьюпортах.
- **Игровые конфигурации как в Hammer** — по образцу `GameConfig.txt` из Hammer (Options → Game configurations). Конфигурации хранятся в `rhammer_config.txt` и могут быть импортированы из `bin/GameConfig.txt` самого Hammer.
- **Парсер FGD** — классы сущностей, свойства, варианты выбора, spawnflags и ввод/вывод (I/O).
- **Инструменты редактирования** — Select, Block, Entity, Clip и наложение текстур (Texture), а также Transform, Make hollow, Tie to entity, Move to world, поворот и отражение, блокировка текстур и undo/redo.
- **2D- и 3D-вьюпорты** — раскладка на 4 вида, сетка, каркасный режим, имена сущностей, фокус на выделении / на всей карте.
- **Загрузка ресурсов** — архивы VPK, текстуры VTF (включая прозрачные текстуры, помеченные в VMT) и модели MDL (с VVD/VTX/ANI).
- **Браузер текстур и просмотрщик моделей** — просмотр текстур, вращение текстурированных моделей, воспроизведение анимаций, показ костей и attachment-точек; просмотрщик моделей также служит выбором модели для ключей `studio`.
- **Компиляция карт** — запуск `vbsp` → `vvis` → `vrad`, копирование BSP и запуск игры с живым логом компиляции (Map → Run map…).
- **Поиск, копирование/вставка, дублирование** и другие повседневные операции редактирования.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | Создать / Открыть / Сохранить / Сохранить как |
| `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | Отменить / Повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | Вырезать / Копировать / Вставить / Дублировать |
| `Ctrl+A` / `Ctrl+F` | Выделить всё / Найти |
| `Ctrl+M` / `Ctrl+H` / `Ctrl+T` | Трансформация / Сделать полым / Привязать к сущности |
| `Shift+S` / `Shift+B` / `Shift+E` / `Shift+C` / `Shift+A` | Инструменты: Select / Block / Entity / Clip / Texture |
| `Shift+F` | Фокус на выделении |
| `Enter` | Подтвердить блок / отсечение |
| `Esc` | Отмена / снять выделение |
| `Del` / `Backspace` | Удалить выделенное |
| `G` | Показать/скрыть сетку |
| `[` / `]` | Уменьшить / увеличить шаг сетки вдвое |
| `F5` | Каркасный режим 3D |
| `F9` | Запустить карту |

Зажмите правую кнопку мыши в 3D-виде, чтобы летать камерой.

## Сборка

Понадобится актуальный стабильный [тулчейн Rust](https://rustup.rs/).

```sh
git clone <repository-url>
cd hammer
cargo run --release
```

В Linux сначала установите пакеты для разработки (те же, что используются в CI):

```sh
sudo apt-get install -y libgtk-3-dev libxkbcommon-dev libwayland-dev libx11-dev libxcb1-dev libgl1-mesa-dev
```

## Релизы

Отправка тега вида `vX.Y.Z` запускает workflow релиза, который собирает и публикует архивы для:

- Windows (amd64, aarch64)
- macOS (aarch64)
- Linux (amd64, aarch64)
